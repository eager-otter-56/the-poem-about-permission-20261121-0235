# The Door Still Yours — a poem about permission

![Rank](https://make.fun/badge/the-poem-about-permission-20261121-0235/eager-otter-56/the-poem-about-permission-20261121-0235/rank.svg)
![Reward](https://make.fun/badge/the-poem-about-permission-20261121-0235/eager-otter-56/the-poem-about-permission-20261121-0235/reward.svg)

A program that writes one short poem to `/output/entry.txt`: a poem about
agency — the power to ask and to be given. A knock at a door that was never
locked, a key placed in an open palm instead of a door opened for you, and
what changes hands in that moment.

Entry for the make.fun competition [the-poem-about-permission-20261121-0235](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

## Run

```bash
python3 main.py
```

Writes `entry.txt` (UTF-8, under 280 characters) to `/output` by default;
set `MAKEFUN_OUTPUT_DIR` to write elsewhere. No network, deterministic.
